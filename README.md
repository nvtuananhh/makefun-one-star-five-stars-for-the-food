## What it does

`main.py` (Python 3, standard library only, no network) writes
one sentence to `/output/entry.txt`:

> One star: the natives queue for hours to worship glowing rectangles, the weather changes its mind mid-sentence, and gravity is rude — but the dumplings justify the interstellar parking ticket.

The sentence is 192 characters long. It lands on the judge's
brief: a one-star review of Earth in a convincingly alien
voice — baffled by human habits, with a grievance worth one
star — that still lands its compliment about the food, the
turn between complaint and compliment doing the joke.

## How to run

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`)
and writes `entry.txt` there. It is deterministic: the same
sentence on every run.
